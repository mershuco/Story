# LCK Manager — Codex 인수인계 패키지

이 패키지는 ChatGPT의 긴 설계 대화를 **원문 그대로 복제한 파일이 아니라, 개발에 필요한 요구사항을 통합**한 것입니다.

- `PROJECT_SPEC.md`: 게임 시스템 상세 기획서
- `AGENTS.md`: Codex가 지켜야 할 핵심 개발 원칙
- `data/선수능력치_초안.xlsx`: 이전 대화에서 만든 능력치/잠재력 **검증 전 초안**

## Codex에 시작 프롬프트

> 이 저장소의 `AGENTS.md`와 `PROJECT_SPEC.md`를 읽고 LCK Manager의 MVP를 구현해줘. 우선 React + TypeScript + Vite로 시작해. 첫 화면에서 2022 시즌 LCK 10팀 중 하나를 선택하고, 2021년 말 스토브리그에서 가상 계약을 관리한 뒤, 버튼 한 번으로 2022 LCK 스프링 전체 정규시즌을 진행하고, 순위·선수/감독/코치 평가를 확인할 수 있게 만들어줘. 플레이어 구단 1군은 정확히 5명으로 제한하고, 모든 AI 팀도 같은 재정/계약 규칙을 따르게 해줘. 테스트도 작성해줘. 구현 전 사실 확인이 필요한 계약·로스터 및 규정은 임의의 실제 사실로 둔갑시키지 말고 표시해줘.

## 원본 채팅 전체를 추가하고 싶다면

ChatGPT Settings > Data Controls > Export Data에서 대화 내역을 내보낸 후, 해당 대화를 찾아 원문을 텍스트 또는 Markdown 파일로 저장해 이 저장소에 추가하세요. 개인 데이터가 포함될 수 있으므로 공개 저장소에 전체 대화 내역을 커밋하지 않는 편이 안전합니다.

## 구현된 첫 버전 (0.1.0)

2022 스프링 한 시즌을 플레이할 수 있는 React + TypeScript 게임입니다.
전체 범위와 가정은 [ASSUMPTIONS.md](ASSUMPTIONS.md)를 확인하세요.

### 가장 간단하게 플레이하기

빌드 결과인 `releases/LCK-Manager.html`을 Chrome 또는 Edge에서 여세요. 서버나 계정 없이 실행됩니다.
파일을 처음 배포하려면 아래 `npm run package:offline`을 실행합니다. 비공개 모드/저장 차단 설정에서는 자동 저장이 실패할 수 있으므로 게임의 **저장 파일 내보내기**로 백업하세요. 파일을 옮기거나 다른 브라우저를 사용하면 자동 저장 공간이 달라질 수 있습니다.

### 개발 환경

Node.js 22.12 이상(이 환경에서 검증한 버전: 24.19.0), npm이 필요합니다.

```bash
cd /workspace/Story
npm ci
npm run dev
```

기존 체크아웃을 그대로 사용합니다. 각 클라우드 작업은 이미 격리되어 있으므로 별도 worktree는 만들지 않습니다.

```bash
npm test                # 엔진: 정규시즌, 대진, 계약, AI 재정, 저장 복원
npm run build           # TypeScript 검사 + 프로덕션 빌드
npm run test:e2e        # Chromium 브라우저에서 전체 흐름, 모바일, 저장 파일 검증
npm run package:offline # 빌드 + 단일 오프라인 HTML 생성
```

브라우저 테스트는 `/usr/bin/chromium`을 기본 사용합니다. 다른 위치라면 `CHROMIUM_PATH`를 지정하세요. 별도 Chromium 설치가 필요할 경우 공식 Playwright 설치 절차와 네트워크 허용 정책을 확인하세요. 개발 실행에 브라우저 자동화 도구 설치는 필수가 아닙니다.

### 플레이 순서

1. 구단 선택 → 스토브리그 시작. 같은 시드와 행동은 같은 결과를 만듭니다.
2. 이적시장에서 FA 영입 → 2군 합류 → 선수단에서 동일 포지션 주전과 교체 콜업.
3. 개인별 훈련과 팀 전략 설정, 필요한 지도자와 계약, 현금과 보장액 확인.
4. **정규시즌 전체 진행** → 범위 확인 → 90경기 자동 진행.
5. 플레이오프 1라운드 → 4강 → 결승을 라운드별 진행. 탈락해도 전체 대진은 끝까지 진행됩니다.
6. 각 단계의 평가와 경기 기록을 확인하고 저장 파일을 내려받습니다.

### 파일 구성

- `src/engine/`: 순수 게임 로직, 타입, IndexedDB/JSON 저장
- `src/data/2022.json`: 미검증 2022 스프링 시범 규칙 및 구단 설정
- `src/data/players.json`: 첨부 엑셀에서 가져온 2022 선수 능력치 초안
- `scripts/import_players.py`: 원본 엑셀에서 데이터 재생성(파이썬 표준 라이브러리만 사용)
- `tests/`: 엔진 및 브라우저 기능 테스트

외부 API, 계정, 비밀 키 없이 로컬에서 작동합니다. 이 버전은 비공식 팬 프로젝트이며 공식 LCK 제품이 아닙니다.

관리형 클라우드 브라우저는 파일 URL 접근을 차단하므로, 단일 HTML은 로컬 HTTP로 제공하여 구단 선택·90경기 진행·자동 저장 복원과 외부 요청 0건을 검증했습니다. 이 환경에서 파일 더블클릭 실행 자체는 검증하지 못했습니다.
