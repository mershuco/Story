# LCK Manager —2026 시즌

2026년 LCK 선수·구단·패치와 대회 진행을 바탕으로 만든 브라우저 구단 운영 게임입니다. VCT Manager를 참고한 집무실 화면에서 날짜·선수단·훈련·재정·이적을 관리하고, 실제 중계형 밴픽과 움직이는 챔피언 초상화로 경기를 진행합니다. 기본 시작은 **2026년1월8일**입니다.

## 공개 웹페이지와 GitHub Pages 배포

**플레이:** https://mershuco.github.io/Story/

**소스:** https://github.com/mershuco/Story

공개 GitHub Pages에서 실행하는 독립 정적 웹게임입니다. ChatGPT·GitHub 로그인이나 API키가 필요하지 않습니다. 플레이 기록은 접속한 기기의 브라우저에 저장됩니다.

`main` 브랜치에 커밋을 올리면 `.github/workflows/pages.yml`이 Node 테스트를 실행하고, 성공한 커밋의 `dist/`를 GitHub Pages에 자동 배포합니다. 배포는 업로드된 아티팩트 ID와 워크플로 OIDC 토큰을 공식 GitHub Pages API에 전달하며 완료 상태까지 확인합니다. 과거 `gh-pages` 브랜치는 배포 원본으로 사용하지 않습니다. 저장소 Settings → Pages의 배포 소스는 **GitHub Actions**입니다. Actions의 **Test and deploy LCK Manager**에서 수동 실행도 가능합니다.

## 실행

Node.js20 이상, Python3. npm 의존성 설치나 빌드가 필요 없습니다.

```bash
npm run dev
npm test
```

`http://localhost:4173`으로 접속합니다. 정적 호스팅에는 `dist/` 전체를 배포하세요. JSON을 사용하므로 `file://` 직접 실행은 지원하지 않습니다.

## 영입과 트레이드

시즌 시작부터 Worlds 종료까지 휴식기·국제대회 기간을 포함해 **다른 구단 선수 직접 영입을 금지**합니다. 동일 포지션 선수의 **1대1 트레이드 신청**만 가능하며 다음 날 경기 전에 상대 구단이 검토합니다. FA는 시즌 중에도 계약할 수 있습니다. 프리시즌·시즌 종료 후에는 직접 영입과 즉시 검토 트레이드를 모두 지원합니다.

신청 화면에서 우리 선수를 직접 고릅니다. 상대는 현재 능력·잠재력·연봉·남은 계약과 주전 전력 유지를 기준으로 수락 또는 거절합니다. 이는 게임용 판단이며 실제 LCK 계약 규정·협상 절차를 재현한 것은 아닙니다. 수락 시 기존 계약·연봉·선수별 성장 기록을 승계하고 양 팀 주전이 빠지면 교환 선수로 대체합니다. 추가 이적료는 없습니다.

검토 전까지 소속은 유지되며 신청 취소가 가능합니다. 검토 중인 선수의 중복 신청·직접 영입·방출을 막습니다. 신청·답변 내역과 검토 날짜는 이적시장에 표시하고 기존 저장 파일도 지원합니다.

## 밴픽과 배치

- **First Selection:** 선택권을 가진 팀이 진영(블루/레드) 또는 픽 순서(선픽/후픽) 중 하나를 먼저 정합니다. 상대가 다른 항목을 결정합니다. 레드 선픽도 가능하며 밴·픽20행동 전체가 선픽 팀을 기준으로 진행됩니다. 다음 세트 선택권은 직전 패자에게 갑니다. CUP·LCK 결승1세트에서는 승자조 우승팀이 두 항목을 모두 선택합니다.
- **선택 중에는 포지션을 정하지 않습니다.** B1~B5/R1~R5는 선택 순서이며 선수나 라인과 연결되지 않습니다. 역할 필터·코치 추천은 검색과 조언입니다.
- 각 팀3밴 → 선픽1/후픽2/선픽2/후픽1 → 각 팀2밴 → 후픽1/선픽2/후픽1의 순서입니다. 연속2픽도 각각 확정하며 화면에 현재 몇 번째 선택인지 표시합니다. 선픽은 진영색과 독립적입니다.
- 양 팀20행동 완료 후 **60초 배치 단계**로 넘어갑니다. 선택한5챔피언을 TOP/JGL/MID/BOT/SUP 선수에게 드래그하거나 선택 상자로 배정합니다. 어떤 챔피언도 모든 포지션에 넣을 수 있습니다. 이미 배정된 두 챔피언은 교환됩니다.
- 시간 정지·재개, 코치 전체 추천 배치, 남은 빈칸만 자동 완성이 가능합니다. 시간이 끝나도 경기는 자동 시작되지 않으며 사용자가 확정해야 합니다. 배치와 난수 상태는 저장됩니다.
- 수동 밴픽과 남은 밴픽 자동은 같은 배치 단계로 연결됩니다. 시리즈 전체 자동은 코치가 배치까지 수행합니다. 제출한 선수 라인업은 밴픽 중 변경할 수 없습니다.
- 하드 피어리스로 이전 세트 양 팀의 픽10종을 다음 세트에서 제외합니다. BO5의5세트도 누적40종을 제외합니다. 현재 세트 밴은 다음 세트에서 초기화됩니다.

## 후반 세트의 OP 확보와 보호 밴

1세트의 AI는 기존 상대 위협·숙련·메타 밴을 사용합니다. 2세트부터는 **자기 팀이 직접 쓸 주력 OP를 정하고, 그 픽의 카운터·대응 수단을 우선 밴**합니다. 2세트는 자기 주력1개,3세트 이후는 주력·대안 최대2개를 준비합니다. 양 팀의 선픽 확보와 후픽 교환을 위해 잔여 파워 픽1~2개를 열어 두며 실제 인원·포지션 구성에 맞으면 우선 확보합니다.

- 당시 관측 메타·선수 숙련·피어리스 잔여 풀로 후보를 고릅니다. 앞 세트의 픽은 여전히 양 팀 모두 재사용 불가이며 신규 챔피언 유예도 유지합니다.
- 예를 들어 돌진형 주력을 위해 포피·탈리야, 진입형 주력을 위해 모르가나·잔나, 투사체 주력을 위해 브라움·야스오 같은 대응 수단을 보호 밴 후보로 봅니다. 보호 대상·밴 이유는 실제 자동 선택 기록에 저장합니다.
- 상대가 먼저 주력을 가져가거나 밴하면 현재 자기 팀이 확보할 수 있는 다른 주력으로 전환합니다. 상대가 가져간 픽을 보호하기 위한 밴은 하지 않습니다. 상대의 남은 포지션에 맞지 않는 카운터도 우선하지 않습니다.
- 모든 챔피언을 무조건 강제 픽하지 않으며 조합·숙련에 크게 맞지 않으면 다른 픽을 선택합니다. 밴픽 중 포지션은 계속 미배정이며 종료 후 배치합니다. 계획과 난수는 저장돼 재접속해도 다시 뽑히지 않습니다.

카운터 관계는 보관된 공식 스킬 기전을 해석한 **게임용 드래프트 판단**입니다. 패치별 실전 라인전 승률표나 무조건 이기는 상성을 뜻하지 않습니다. [판단 규칙](dist/draft-matchups.js), [20개 BO5 연속 드래프트 측정](qa/draft-opening-policy-results.json), [실제 UI의 OP 교환·보호 밴 검증](qa/draft-openings-browser-results.json)을 제공합니다.

```bash
node scripts/measure_draft_openings.mjs
python qa/draft_openings_test.py
```

- CUP PO직행은 승자 그룹1·2위와 패자 그룹1위입니다. 나머지6팀 플레이인과1R부터의 완전 더블 엘리미네이션10시리즈를 진행합니다. CUP결승은3월1일, 상위2팀이 First Stand에 진출합니다.

- **MSI:** LCK/LPL/LEC/LCS/LCP 각2팀과 CBLOL1팀, 총11팀입니다.6지역1시드와 First Stand에서 가장 높은 성적을 낸2시드 보유 지역의2시드가 직행합니다. 플레이인4팀 완전 더블 엘리미네이션에서1팀만8팀 본선에 진출합니다.6월28일~7월12일입니다.

- **Worlds:**6지역19팀.4팀BO5 완전 더블 엘리미네이션에서1팀만16팀 스위스로 진출합니다.3승 진출·3패 탈락, 결정전BO3, 재대결 방지,1R지역 분리를 적용합니다.8강·4강·11월14일 결승으로 마무리합니다.

국내 규칙과 날짜의 근거는 [공식 규정 정리](research/2026/domestic-rules.md)에 있습니다. 요청에 따라 실제2026 형식의 정규3·4R를 3~5R로 확장하고 아시안게임 일정을 두지 않습니다. 추가 라운드 뒤 플레이인·플레이오프를2주 늦추며, 월즈 시작일은 유지합니다. 진행 중인 구형3·4R 저장은 기존 경기 ID·결과·일정·난수를 보존하고5R20시리즈만 추가합니다. 이미 플레이오프로 넘어간 저장의 완료 경기를 되돌리지는 않으며 다음 시즌부터 새 구성을 적용합니다. 기존2022 저장 파일은 이전 선수·12.x패치·2025형식으로 복원합니다.

## 2026 대회별 OP·주요 픽 보기

밴픽창에서 **현재 대회만 참고하는 TOP/JGL/MID/BOT/SUP 추천**을 제공합니다. 컵125세트, First Stand45세트, 정규1·2R204세트, Road to MSI20세트, 후반 정규98세트, 플레이인·플레이오프55세트, MSI71세트, 월즈22세트의 확인 기록을 분리합니다. 다른 대회·리그의 메타로 대체하지 않습니다. 같은 대회 전체 세트의 픽·승수, 현재 패치 우선도, 시리즈 세트 번호, 실제 동반 조합·같은 라인 맞대결 기록과 선수 숙련도를 추천 점수에 반영합니다. 점수는 승률이 아니며 승패·팀 전력·소표본의 영향을 완전히 제거한 모델도 아닙니다.

기본 `대회 전체 기록`은 해당 대회의 진행일 이후 기록도 포함한 회고 참고표입니다. `현재 시점 참고`도 같은 대회 안에서 게임 날짜 이전 기록만 사용합니다. 자료가 없으면 다른 대회 자료를 가져오지 않고 미관측 숙련도 기반 대체 픽으로 구분합니다. OP는 같은 대회의 적용 패치1세트 표본10경기 이상·P/B65% 이상인 관측 분류이며 확정 승률을 뜻하지 않습니다. 소진된 픽은 다음 선택 가능 후보로 자동 보충합니다.

챔피언을 누르면 **누른 사진 아래에 현재 차례의 ‘픽’ 또는 ‘밴’ 버튼**이 나타납니다. 전체 목록과 대회 추천 모두 같은 방식이며 버튼을 눌러야 확정됩니다. 양 팀 밴픽 현황은 화면 하단에 고정되고 챔피언 선택 영역만 스크롤됩니다. 선택과 확정 후에도 목록 스크롤 위치를 유지하며, 포지션은 밴픽 종료 후 자유롭게 배치합니다.

**게임은3~5R를 진행하지만 확인된2026 후반 정규 실전 자료는3·4R98세트이며 실제5R 자료는 없습니다. 월즈는10월18일까지22세트만 확보해 전체 대회 기록을 확인하지 못했습니다.** 화면에도 이를 표시합니다. 상대 AI의 기존 지식·난수·경기 계산에는 회고 추천 자료를 주입하지 않습니다. [집계·추천 기준과 검증](research/2026/draft-meta-guide.md)을 참고하세요.


밴픽의 ‘OP·주요 픽 보기’와 그 아래 ‘조합 보기’는 접힌 상태로 시작합니다. 조합 탭에서 챔피언을 골라 스킬 연계와 해당 대회의 동반 출전 기록을 조회할 수 있습니다. 같은 대회에서 한 팀으로 1세트 이상 출전한 조합을 표시합니다. 확인한 640세트에서 동반 조합 3,212종을 집계했고, 오리아나·녹턴과 암베사·바이 등 스킬 연계 157종은 두 챔피언이 함께 살아서 참가한 교전의 확률에 반영합니다. [조합 자료와 효과 적용 기준](research/2026/champion-synergies.md)

## 관전 화면

점수판 바로 아래에 양 팀 선수 현황과 중앙 미니맵을 배치합니다. 맵과 선수 패널은 브라우저의 실제 표시 높이에 맞춰 조정하며 점수판·해설·진행 버튼·장면 타임라인을 한 화면에 배치합니다. 휴대폰 세로 화면에서는 정사각형 미니맵을 왼쪽에 배치하고, 오른쪽에 킬 로그와 바론·장로 타이머를 위에서 아래 순서로 표시합니다. 넓은 화면에서는 킬 로그를 오른쪽 선수 패널 옆에 표시합니다. 해설은 맵 아래에 표시합니다. 바론·장로 표시, 현상금 안내, 해설의 공간은 높이를 고정하고 장면 전환 시 맵 크기를 이어받아 후반 재생 중 확대·축소가 반복되지 않도록 했습니다. 긴 해설은 해설 영역 안에서 스크롤해 읽을 수 있습니다. 운영 선택창은 맵 위를 덮으며, 내용이 길면 설명 영역만 스크롤되고 선택 버튼은 고정됩니다. 휴대폰에서는 맵 아래에 양 팀 선수 현황을 나란히 표시합니다. 완료된 경기의 상세 기록표는 첫 화면 아래에서 스크롤해 확인합니다. 오브젝트 효과 설명·수입 내역·시야 요약·별도 골드 차이 패널은 제거했습니다. 총 골드 우위는 앞선 팀의 총 골드 바로 아래에 `+14.9k`처럼 표시하고, 역전되면 반대편으로 옮깁니다. 선수별 KDA·CS·골드와 동일 포지션 대비 골드 차이는 선수 현황에 남습니다.

## 경기 중 오브젝트 선택과 팀 운영

수동 밴픽 후 배치를 확정하면 **진행 중 경기**가 시작됩니다. 오브젝트 직전에 **상대 팀이 우리 팀보다4,500G 이상 앞선 경우에만** 진행을 멈추고 수동 선택창을 띄웁니다. 그 미만이거나 우리가 앞서면 코치의 자동 판단으로 이어갑니다. 용·유충·전령·바론·장로 앞의 위기 선택창에는 **우리 한타·교전 승리 확률과 오브젝트 확보 예상 확률**을 별도로 표시합니다. 세트 결과는 해당 구간의 선택을 반영해 계산합니다.

- **싸우기 · 오브젝트 경합:** 교전 전력·골드·성장·KDA를 반영한 교전과 오브젝트 마무리 싸움을 진행합니다.
- **포기 · 사이드 운영:** 상대에게 오브젝트를 양보하고 반대 라인의 실제 자원·포탑을 노립니다. 상대도 교환을 선택하면 오브젝트를 잠시 보류합니다. 버프·영혼을 포기하는 기회비용이 있습니다.
- **이번 판단 자동:** 현 상황과 운영 성향을 보고 코치가 이번 결정만 내립니다.
- **남은 세트 자동 진행:** 현재까지의 선택을 유지하고 남은 세트의 판단과 결과를 자동으로 진행합니다.

상단에 **용 종류·유충 획득 아이콘**이 표시됩니다. 유충은2026 기준 한 번 등장하는3개체를 개별 경합하므로2:1 같은 분배가 가능합니다. 첫 세 용은 서로 다른 종류를 무작위로 정하고, **셋째 용부터 같은 종류가 계속 등장**합니다. 한 팀이 종류 합산4용을 먹으면 셋째 종류의 영혼을 영구 획득하고, **6분 뒤부터 장로용**으로 전환합니다. 장로를 일반 용 카운터에 중복 합산하지 않습니다. 이전 버전이 기록하지 않은 유충 수는 `—`로 표시합니다.

화염·대지·바다·바람·마법공학·화학공학의 영구 중첩과 영혼을 분리해 조합·교전 형태에 따라 계산합니다. 관전 점수판에서 획득 용 종류와 영혼을, 바론·장로 보유 팀 카드에서 남은 시간을 확인할 수 있습니다. **바론180초**는 미니언·공성·빠른 귀환을, **장로150초**는 화상·처형에 따른 한타와 마무리를 강화합니다. 보유자가 죽으면 해당 강화만 잃고 영구 중첩은 남습니다. 유충3마리 독식은 진드기 소환을 추가해 공성이 더 강합니다.

요청한 게임 규칙에 따라 **바론 둥지는 유충·바론만**, **용 둥지는 원소용·장로용만** 등장합니다. 새 세트에는 전령이 없습니다. 실제 일반 협곡에는 전령이 존재합니다.

포기 자체로 지급하던 **800~1,500G 확정 보상은 폐지**했습니다. 추가 라인·정글 자원은 실제 확보한 미니언·캠프에 따라 **한 운영당 합계 0~350G**, 포탑 골드는 실제 파괴한 경우에만 별도 지급합니다. 상대도 보류하면 기본 파밍만 진행합니다. [경제 모델 수정·공식 근거·검증 결과](research/2026/economy-v10.md)에 이전 문제와 새 규칙을 기록했습니다.

오브젝트 확보는 한타 승리와 별도로 계산합니다. 골드·전력·조합에 따른 교전 전망, **확보 직전 정글러 생존**, 정글러의 강타 지수, 준비된 마무리 수단이 함께 작용합니다. 칼리스타의 창 뽑기·자야의 깃털 회수·초가스의 포식·누누의 잡아먹기·판테온의 낮은 체력 마무리 등을 차등 반영합니다. 진입하지 않은 챔피언이나 확보 전에 사망한 챔피언은 마무리 보너스를 주지 않습니다. 교전 후 안전하게 확보하거나, 오브젝트를 먼저 마무리하는 경합을 구분해 한타를 이긴 팀도 스틸당할 수 있습니다.

강타 지수는 `선수 OVR×0.8 + 해당 챔피언 숙련×0.2 − 피로×0.06`을40~99점으로 제한한 **게임 추정 능력**입니다. 실제 선수의 검증된 강타 성공률·순위가 아닙니다. 챔피언의 마무리 계수도 공식 피해량을 그대로 재현한 값이 아니며, 중첩 준비·확보 시 생존·교전 통제에 따라 포화되는 게임 평가입니다. 선택창의 예상 확보 확률은 경합을 가정한 전망이며 교전 뒤 생존 상황에 따라 달라집니다.

기존의 고정된 갱킹→용→다이브→한타 순서를 제거했습니다. 팀의 **게임용 운영 성향**, 초반/후반 전략, 밴픽의 결투·포킹·진입·성장 특성, 현재 골드·오브젝트 상황으로 갱킹 위치·소규모 교전·파밍·시야·사이드·공성·한타를 선택합니다. 몬스터 생성 시간과 재등장 간격은 지키되 실제 시도 시점은 운영과 선택에 따라 달라집니다. 운영 성향은 실제2026 구단의 정밀 통계 모델이 아닌 게임 설정입니다.

진행 중 경기의 선택창·로그·난수는 저장되며 새로고침으로 다시 추첨하지 않습니다. 경기 중 선수단 변경·날짜 진행·트레이드 처리는 잠깁니다. 종료된`event-v5`·`event-v6` 경기 로그는 저장된 시작 난수와 수동 선택으로 정확히 복원해 저장 용량을 줄입니다. 자동 저장·슬롯·파일 내보내기가 같은 방식을 사용하며 진행 중 로그는 그대로 보관합니다.

상단은 팀 골드·킬·포탑·용 종류 아이콘을, 양옆은 선수별 **K/D/A·CS·레벨·누적 골드와 상대 포지션 대비 골드 차이**를 표시합니다. 개인 골드 합계는 팀 골드와 일치합니다. 용6종·장로·바론·유충·와드는 실제 게임 아이콘을 로컬로 제공합니다.

- 리 신·레넥톤·엘리스는 초반 교전, 케일·카사딘·징크스·스몰더는 성장 후 전투에 더 강하게 평가합니다. 나서스의 중반 전성기·후반 접근 한계와 케이틀린의 중반 공백도 구분합니다.
- 피오라·잭스 같은 결투형과 케넨·아무무 같은 광역 한타형을 구분합니다. 상체3대3은 TOP/JGL/MID, 하체 다이브는 JGL/BOT/SUP만 평가하므로 멀리 있는 캐리의 성장·전과가 그 교전 확률을 바꾸지 않습니다.
- **매 교전 직전의 실제 K/D/A**로 개인 영향력을 다시 계산합니다. 킬과 어시스트는 성장 강점을 앞당기고 데스는 성장을 지연시키며, 성장 민감도가 높은 딜러·암살자는 더 크게 반응합니다. 탱커·서포터의 CC·보호 가치는 열세에서도 더 많이 남습니다. 같은 팀 골드·킬 합계라도 누가 킬을 먹었는지에 따라 전투력이 달라집니다.
- 현재 교전에서 얻을 킬을 미리 반영하지 않습니다. 전과 변화는 **다음 교전부터** 적용합니다. 초반형이 많이 죽었다고 초반 전투력으로 되돌아가는 역보정도 막습니다. 유리해도 무조건 승리하거나 불리하다고 CC가 없어지지 않습니다.
- 기존의 단순 초반형·성장형 개수 보정은 제거하고 개별 곡선으로 대체했습니다. 배치 화면은 초반·후반의3대3/5대5 네 상황과20분/45분 한타 예상치를 표시합니다. 관전에는 시간대·교전 참가 범위·실제 챔피언 KDA 영향이 표시됩니다.

**확인 범위:** 공식 Data Dragon 스킬 설명과 기전에 대한 정성적 해석입니다. 평가1~5점과 확률 계수는 게임용 추정이며 패치별·시간대별 실전 승률로 보정한 자료가 아닙니다. 실제 레벨·아이템·개별 스택·궁극기 쿨다운·진화·변신·빌드 분기를 전부 추적하지 않으며 시간과 전과로 근사합니다. 로크 등 신규 챔피언의 실전 평가는 제한적입니다. 패치별 버프·리워크의 모든 수치가 개별 성장 곡선에 재학습되었다고 주장하지 않습니다.

모델의 전과 순점수는 `킬 + 0.35×어시스트 − 0.9×데스`입니다. 성장 민감도에 따라 성장 시점을 최대6분 앞당기거나8분 지연하며, 실제 상승 구간만 이동시킵니다. 전과 영향은 포화 함수로 제한하고 교전 참가자 평균으로 반영합니다. 개인 성장·전과와 진형의 종합 보정은 기존 조합 확률 상한을 공유합니다. 팀 골드·선수 전력·버프·전략은 별도 요인으로 함께 적용합니다.

동일 전력·골드·버프의 예시에서 레넥톤/리 신/르블랑/드레이븐/파이크 대 케일/킨드레드/카사딘/징크스/소나의 초반형 팀 확률은8분 상체3대3 약69.0%,45분5대5 약28.9%입니다. 이는 특정 게임용 조합의 예시이며 챔피언 자체의 고정 승률이 아닙니다. KDA 분배 비교와 조합별400경기씩의 가상 시뮬레이션은 [측정 결과](qa/champion-combat-balance-results.json)에 있습니다.


## 골드·강팀·챔피언 조합과 역전

승자를 미리 정하지 않고 교전마다 전력·골드 차이·챔피언 조합·버프·전략에 따라 확률을 계산합니다. 동일한 전력·조합·버프·교전 변수라면 중반6,000G 우위는 **75%**,12,000G 우위는 **90%**의 한타 승률입니다. 골드 차이가 커질수록 우위가 강해지며 전체 보정 후 확률은2~98%로 제한합니다. 실제 LCK 통계가 아닌 게임용 설정입니다.

| 골드 우위 |20분|40분|50분|
|---:|---:|---:|---:|
|3,000G|63.4%|60.8%|56.8%|
|6,000G|75.0%|70.7%|63.4%|
|10,000G|86.2%|81.2%|71.4%|
|12,000G|90.0%|85.3%|75.0%|

35~40분에 골드 가중치를100%에서80%로 부드럽게 줄이고,40분 이후에는45분65%,50분50%,55분 이후35%까지 줄입니다. 골드 수치 자체는 유지하며 확률에 미치는 영향만 줄입니다.35분까지는 기본 가중치100%입니다.

강팀은 현재 주전 전력·컨디션·사기·팀워크로 판단합니다. 전력8점 우위의 팀은 다른 조건이 같을 때6,000G 열세에서 약36.9%, 우위에서 약84.0%의 한타 승률을 갖습니다. 동급 팀은 각각25%/75%,8점 열세 팀은 약16.0%/63.1%입니다. 강팀의 우위 유지와 열세 극복 보정을 추가하며, 바론 스틸·수비 확률에도 전력 차이가 반영됩니다. 구단 이름·인기·예산으로 승리를 보장하지 않습니다.

챔피언별 역할·특성과 실제 배치를 이용해 전방, 진입, 딜러 보호, 포킹, 지속딜, 물리/마법 피해 균형, 초반 주도력과 후반 성장성을 평가합니다. 진입 대 포킹, 보호 대 다이브, 단일 피해 유형 대 전방 등 상대 조합과의 상성도 반영합니다. 밴픽 뒤 배치 화면에서 조합 요약과20분/45분의 **조합만 비교한 예상 한타 승률**을 볼 수 있습니다. 실제 교전에는 선수·골드·버프가 추가되며, 이 수치는 공식 챔피언 승률이나 스킬 서버 판정이 아닙니다.

관전의 처치·어시스트·골드·오브젝트·승패는 같은 이벤트 기록을 사용합니다. AI 경기의 긴 로그는 저장된 난수와 시작 조건에서 재현합니다. 장기전의 골드 반영 비중과 조합 우위를 화면에 표시합니다. 기존`event-v2`·`event-v3`·`event-v4`의 시뮬레이터·조합 규칙을 별도 보관해 예전 경기의 승패·KDA·골드 재생을 유지합니다. **새로 진행하는 세트부터** 시간대·개인 전과·오브젝트 판단·가변 운영을 반영한`event-v5`를 적용합니다.

게임 균형용 가상팀2,000경기씩의 결과와 기본 확률표는 [골드 기본 모델 측정 결과](qa/comeback-balance-results.json), 이전 결과는 [v2 기록](qa/comeback-balance-v2-results.json)에 있습니다. 실제 대회의 결과 예측이나 고정된 역전 발생률 보장이 아닙니다.


## 확인 범위와 간소화

**기본 2026 메타 원장은 10월 18일까지**입니다. 이후 날짜는 마지막 확인된 메타를 표시합니다. 숙련도에는 11월 14일 월즈 결승 및 11월 21일까지 확인한 일부 다른 대회의 출전도 반영합니다.

그룹 선발·상대 지명은 코치가 자동 결정합니다. LCK밖의 지역 리그 전체를 운영하지 않으며 확보한 해외 구단 풀의 전력으로 대표를 정합니다. 일부 다자 동률·지역 성적의 세부 타이브레이커와 시드 추첨을 간소화했습니다. 릴레이 첫 선택권은 일반 홈팀 규칙을 적용한 게임 해석입니다. 사무국의 예외 판정·일정 변경 원장 전체를 구현하지 않았습니다.

2026 구단명은 확인했지만 모든 최신 로고 파일을 검증하지 못해 현대 프로필은 구단 약자 엠블럼을 사용합니다. 과거2022 로고를2026 로고로 표시하지 않습니다. 브라우저 저장·3슬롯·JSON 내보내기/불러오기를 지원하며 서버 저장은 없습니다. 다음 해로 진행하면2026 자료를 반복하며 실제2027 로스터를 예측하지 않습니다.

수동 경기는 오브젝트 직전 멈추고 선택 후 다음 구간을 계산합니다. 완료된 경기의 관전은 확정된 기록에서 갱킹·교전·오브젝트·귀환·공성을 재구성합니다. 같은SVG 노드의 초상화가 연속 이동하며 체력·사망·킬피드·상황 설명을 표시합니다. K/D/A와 결과·난수를 보존합니다. 실제 LoL의 스킬·아이템·룬·시야·포지션 퀘스트 서버 판정을 재현한 엔진은 아닙니다. 재정·계약도 게임용 추정이며 부상·면담·SFR·온라인 멀티플레이는 미구현입니다.
