# LCK Manager —2026 시즌

2026년 LCK 선수·구단·패치와 대회 진행을 바탕으로 만든 브라우저 구단 운영 게임입니다. VCT Manager를 참고한 집무실 화면에서 날짜·선수단·훈련·재정·이적을 관리하고, 실제 중계형 밴픽과 움직이는 챔피언 초상화로 경기를 진행합니다. 기본 시작은 **2026년1월8일**입니다.

## 공개 웹페이지와 GitHub Pages 배포

**플레이:** https://mershuco.github.io/Story/

**소스:** https://github.com/mershuco/Story

공개 GitHub Pages에서 실행하는 독립 정적 웹게임입니다. ChatGPT·GitHub 로그인이나 API키가 필요하지 않습니다. 플레이 기록은 접속한 기기의 브라우저에 저장됩니다.

`main` 브랜치에 커밋을 올리면 `.github/workflows/pages.yml`이 Node 테스트를 실행하고, 성공한 커밋의 `dist/`를 GitHub Pages에 자동 배포합니다. 과거 `gh-pages` 브랜치는 배포 원본으로 사용하지 않습니다. 저장소 Settings → Pages의 배포 소스는 **GitHub Actions**입니다. Actions의 **Test and deploy LCK Manager**에서 수동 실행도 가능합니다.

## 실행

Node.js20 이상, Python3. npm 의존성 설치나 빌드가 필요 없습니다.

```bash
npm run dev
npm test
```

`http://localhost:4173`으로 접속합니다. 정적 호스팅에는 `dist/` 전체를 배포하세요. JSON을 사용하므로 `file://` 직접 실행은 지원하지 않습니다.

## 밴픽과 배치

- **First Selection:** 선택권을 가진 팀이 진영(블루/레드) 또는 픽 순서(선픽/후픽) 중 하나를 먼저 정합니다. 상대가 다른 항목을 결정합니다. 레드 선픽도 가능하며 밴·픽20행동 전체가 선픽 팀을 기준으로 진행됩니다. 다음 세트 선택권은 직전 패자에게 갑니다. CUP·LCK 결승1세트에서는 승자조 우승팀이 두 항목을 모두 선택합니다.
- **선택 중에는 포지션을 정하지 않습니다.** B1~B5/R1~R5는 선택 순서이며 선수나 라인과 연결되지 않습니다. 역할 필터·코치 추천은 검색과 조언입니다.
- 각 팀3밴 → 선픽1/후픽2/선픽2/후픽1 → 각 팀2밴 → 후픽1/선픽2/후픽1의 순서입니다. 연속2픽도 각각 확정하며 화면에 현재 몇 번째 선택인지 표시합니다. 선픽은 진영색과 독립적입니다.
- 양 팀20행동 완료 후 **60초 배치 단계**로 넘어갑니다. 선택한5챔피언을 TOP/JGL/MID/BOT/SUP 선수에게 드래그하거나 선택 상자로 배정합니다. 어떤 챔피언도 모든 포지션에 넣을 수 있습니다. 이미 배정된 두 챔피언은 교환됩니다.
- 시간 정지·재개, 코치 전체 추천 배치, 남은 빈칸만 자동 완성이 가능합니다. 시간이 끝나도 경기는 자동 시작되지 않으며 사용자가 확정해야 합니다. 배치와 난수 상태는 저장됩니다.
- 수동 밴픽과 남은 밴픽 자동은 같은 배치 단계로 연결됩니다. 시리즈 전체 자동은 코치가 배치까지 수행합니다. 제출한 선수 라인업은 밴픽 중 변경할 수 없습니다.
- 하드 피어리스로 이전 세트 양 팀의 픽10종을 다음 세트에서 제외합니다. BO5의5세트도 누적40종을 제외합니다. 현재 세트 밴은 다음 세트에서 초기화됩니다.

## 2026 시즌 진행

- **CUP:** 바론/장로 그룹 대항25시리즈. 일반20경기는BO3·그룹1점, 동일 선발 시드의 슈퍼 위크5경기는BO5·그룹2점입니다. 개인 전적에는 BO5도1승이며 실제 세트 득실을 반영합니다. 그룹 승점 동률은 세트 득실, 다시 동률이면 그룹5위/1위가 교대하는 피어리스 릴레이BO5로 결정합니다. 릴레이는 코치가 자동 진행합니다.
- CUP PO직행은 승자 그룹1·2위와 패자 그룹1위입니다. 나머지6팀 플레이인과1R부터의 완전 더블 엘리미네이션10시리즈를 진행합니다. CUP결승은3월1일, 상위2팀이 First Stand에 진출합니다.
- **First Stand:** 6지역8팀,4팀GSL그룹2개에서 각2팀 진출 후4강·결승. 전 경기BO5입니다.
- **정규시즌:** 전반기10팀 더블 라운드 로빈90시리즈(팀당18), 후반기Legend/Rise 각5팀 더블 라운드 로빈40시리즈(팀당8). 전반기 성적을 누적해 **총130시리즈·팀당26시리즈**를 치릅니다.
- **Road to MSI:**6위→5위→4위→3위 도전과1·2위전을 결합한5경기.6월14일 두 번째 대표를 확정합니다.
- **MSI:** LCK/LPL/LEC/LCS/LCP 각2팀과 CBLOL1팀, 총11팀입니다.6지역1시드와 First Stand에서 가장 높은 성적을 낸2시드 보유 지역의2시드가 직행합니다. 플레이인4팀 완전 더블 엘리미네이션에서1팀만8팀 본선에 진출합니다.6월28일~7월12일입니다.
- **시즌 플레이인:** Legend5 vs Rise1의5시드전, Rise2 vs Rise3, 앞5시드전 패자와 뒤 경기 승자의6시드전, 총3BO5입니다. 시즌PO는10경기 완전 더블 엘리미네이션이며 패자조 진입을 PO시드로 비교합니다. 결승은9월13일입니다.
- **Worlds:**6지역19팀.4팀BO5 완전 더블 엘리미네이션에서1팀만16팀 스위스로 진출합니다.3승 진출·3패 탈락, 결정전BO3, 재대결 방지,1R지역 분리를 적용합니다.8강·4강·11월14일 결승으로 마무리합니다.

국내 규칙과 날짜의 근거는 [공식 규정 정리](research/2026/domestic-rules.md)에 있습니다. 경기는 실제2026 날짜 구간에 배치하지만 결과는 플레이에 따라 달라집니다. 기존2022 저장 파일은 이전 선수·12.x패치·2025형식으로 복원합니다.

## 교전과 역전

승자를 미리 정하지 않고 교전마다 전력·골드 차이·후반 조합·바론/영혼·전략에 따라 확률을 계산합니다. 골드가 앞서면 유리하지만 불리한 팀도 교전에서 이길 수 있습니다. 제압·오브젝트 보상, 바론 스틸과 후반 성장이 이후 골드·교전·공성 결과를 바꾸고, 실제 넥서스 공성 결과로 승패가 정해집니다. 매 경기 역전이 발생하도록 강제하지 않습니다.

관전의 처치·어시스트·골드·오브젝트·승패는 같은 이벤트 기록을 사용합니다. AI 경기의 긴 로그는 저장된 난수 상태와 경기 시작 조건에서 재현해 저장 공간을 줄입니다. 역전 장면에 ‘골드 역전’, 제압 보상, 이번 교전의 예상 우위를 표시합니다. 기존에 완료된 저장 경기의 승패는 유지하며 **새로 진행하는 경기부터** 새 시뮬레이션을 적용합니다.

게임 균형 검증용 동일 전력 가상팀2,000경기에서 BLUE승률은50.3%, 최종 승자가6,000G이상 뒤졌던 경기는5.45%였습니다. 전력8점 우위의 가상팀은78%를 승리했습니다. 실제 LCK 승률에 대한 예측이나 목표 승률 보장이 아닙니다. [재현 가능한 측정 결과](qa/comeback-balance-results.json)를 제공합니다.

```bash
node scripts/measure_match_balance.mjs
python qa/comeback_test.py
```

## 선수·챔피언·메타 자료

- 국내106명: 개막 주전50명, CL첫 관측 주전50명, 확인된 후보6명. T1의Peyz, HLE의Kanavi/Gumayusi, DK의Smash/Career 등2026 개막 라인업을 사용합니다. DNS/BFX/KRX 등 구단 이름도 갱신했습니다.
- 해외19개 구단95명, 합계 **201명 ×173종 =34,773개 숙련 조합**입니다. 국내106명과 해외94명에게2025 출전 근거가 있습니다. Pop9의 연결되지 않은 기록과 모든 미관측 선수-챔피언 조합은 중립48점·미확인으로 남겼습니다.
- 초기 능력치와 숙련 추정은 **2025 기록만** 사용합니다.2026 성적은 회고용으로 분리하며 개막 AI에 넣지 않습니다. 계정 숙련도나 공식 선수 평점이 아닙니다. 승률·출전량·리그 차이를 완전히 보정한 선수 평가도 아닙니다.
- 챔피언은 시작 패치172종, 최신 수집 패치173종입니다. Riot Data Dragon **26.01~26.23의23개 패치 가용 목록·패시브/QWER 설명**을 수집했습니다. 내부 Data Dragon 버전16.x와 공개 표기26.xx를 구분합니다.
- 실전 메타는42개 주간 스냅샷입니다. 기준일 이전56일의 주요 리그·국제대회·컵 **1세트** 기록으로 픽·밴 비중과 관측 역할을 집계합니다.2025말 기록을 개막 참고값으로 이어 사용합니다. S/A/B 표시는 공식 티어가 아닌 해당 표본의 출현 빈도 구간입니다.
- 실제 LCK에서 해당 패치가 처음 관측된 날짜와 FST26.05/MSI26.13/Worlds26.20 패치를 반영합니다. 신규 챔피언은 출시 패치 유예를 적용합니다. 개별 버그·리워크에 대한 사무국의 추가 금지는 완전한 원장을 확보하지 못했습니다.

[전체 숙련CSV](research/2026/player-champion-mastery.csv) · [출처와 식별자](research/2026/sources.json) · [패치별 회고 메타](research/2026/patch-meta-reports.json) · [공식 챔피언 자료 해시](research/2026/champion-provenance.json)

## 확인 범위와 간소화

**확보한2026 경기 자료는10월18일까지**입니다. 이후 패치·11월 경기·월즈 최종 성적의 실전 통계가 모두 수집되었다고 주장하지 않습니다. 이후 날짜는 마지막 확인된 메타를 표시합니다. 공식 패치 설명과 실제 선수·대회 통계의 확인 범위는 서로 다릅니다.

그룹 선발·상대 지명은 코치가 자동 결정합니다. LCK밖의 지역 리그 전체를 운영하지 않으며 확보한 해외 구단 풀의 전력으로 대표를 정합니다. 일부 다자 동률·지역 성적의 세부 타이브레이커와 시드 추첨을 간소화했습니다. 릴레이 첫 선택권은 일반 홈팀 규칙을 적용한 게임 해석입니다. 사무국의 예외 판정·일정 변경 원장 전체를 구현하지 않았습니다.

2026 구단명은 확인했지만 모든 최신 로고 파일을 검증하지 못해 현대 프로필은 구단 약자 엠블럼을 사용합니다. 과거2022 로고를2026 로고로 표시하지 않습니다. 브라우저 저장·3슬롯·JSON 내보내기/불러오기를 지원하며 서버 저장은 없습니다. 다음 해로 진행하면2026 자료를 반복하며 실제2027 로스터를 예측하지 않습니다.

관전은 확정된 세트 기록에서 갱킹·교전·오브젝트·귀환·공성을 재구성합니다. 같은SVG 노드의 초상화가 연속 이동하며 체력·사망·킬피드·상황 설명을 표시합니다. K/D/A와 결과·난수를 보존합니다. 실제 LoL의 스킬·아이템·룬·시야·포지션 퀘스트 서버 판정을 재현한 엔진은 아닙니다. 재정·계약도 게임용 추정이며 부상·면담·SFR·온라인 멀티플레이는 미구현입니다.

## 검증

Node 테스트는2022저장 호환,2026로스터·패치·메타 날짜 제한,20행동 후 자유 배치·타이머·First Selection·릴레이,130정규 시리즈와 국제대회 완주를 확인합니다.

```bash
npm test
python qa/browser_test.py
python qa/presentation_test.py
python qa/season_2026_test.py
```

브라우저 검증은 Chromium/Playwright 환경에서 실행합니다. `qa/presentation_test.py`는 루트2022자료로version1 호환 fixture를 생성합니다. 결과는 [관리 화면](qa/browser-results.json), [밴픽·관전·모바일](qa/presentation-results.json)에 있습니다.
