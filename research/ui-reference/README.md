# 실제 LoL 방송 밴픽 화면 관찰

2026-11-20 조사. 아래 세 이미지를 다운로드하고 실제로 열어 시각적으로 확인했다. 기사 속 방송 캡처는 연구 참고이며 게임에 삽입하는 아트 에셋과 구분한다. 원문·이미지 URL은 sources.json에 있다.

## 공통 화면 구조

- 화면 대부분은 경기장·선수 카메라 또는 선택한 챔피언의 큰 아트를 보여 준다.
- **밴픽 정보는 하단에 긴 가로 띠로 모인다.** 왼쪽 5개 챔피언 세로 초상화, 가운데 대회·팀 로고·시리즈 점수·패치 정보, 오른쪽 5개 초상화 구성이다.
- 초상화는 정사각 아이콘보다 길쭉한 로딩 아트 크롭이다. 선수 이름은 각 초상화 아래에 붙는다.
- 현재 세트 밴 5개는 각 팀 초상화 바로 위에 작은 정사각 그림으로 배치한다. 밴과 픽을 같은 카드 크기로 만들지 않는다.
- 2025 Worlds 화면에는 선택 순서를 나타내는 B1~B5 / R1~R5 표시가 있다. 이 순서 표시는 실제 최종 라인 배치와 다른 개념이다.

## 시기별 차이

### worlds-2022-final-game5.png

실제 2022 Worlds 결승 5세트의 종료된 밴픽 화면이다. 중앙에 T1 2 대 DRX 2, 양옆에 다섯 챔피언과 선수명이 보인다. 양쪽 선수는 TOP→JGL→MID→BOT→SUP 순서다. 과거 세트 소진 칸이 없다. 이 경기는 피어리스가 도입되기 전 일반 드래프트이므로 기존 세트에 나온 챔피언도 선택할 수 있다.

### lck-2025-broadcast.jpg

T1–HLE, MATCH141, PATCH25.16, 시리즈1:1이다. 하단 현재 챔피언 위에 현재 밴 줄이 있고, 화면 양쪽에는 Game1·Game2로 구분한 이전 사용 챔피언 줄이 쌓인다. 소진된 챔피언에 취소선이 표시된다. 중앙 상단은 큰 챔피언 아트다. 이 방송의 왼쪽 초상화 순서는 SUP→BOT→MID→JGL→TOP으로 뒤집혀 있으며 오른쪽은 TOP→JGL→MID→BOT→SUP이다. 모든 방송에서 같은 선수 순서를 쓴다고 단정하지 않는다.

### worlds-2025-fearless-overlay.jpg

KT–T1 결승 밴픽이다. 현재 밴은 좌우 작은 줄로, 이전 세트 사용 픽은 가운데 **SERIES BAN** 줄로 별도 구분한다. 각 팀 코치 이름은 현재 밴 위에 있다. 아래 초상화에는 B/R 픽 순서, 선수명, 작은 소환사 주문 표식이 보인다. 중앙에는 두 팀 시리즈 점수·로고·대회 로고·PATCH25.20이 있다.

## 게임 화면에 적용할 때

방송용 하단 띠와 플레이어 조작 영역을 분리한다. 하단은 초상화·현재 밴·시리즈 소진·점수로 방송처럼 구성하고, 위쪽에 챔피언 검색·후보·미리보기·확정 버튼을 둔다. 현재 선택 중인 팀/행동은 타이머나 명확한 텍스트로 강조한다. 이 세 캡처는 주로 밴픽 완료 상태이므로 실제 선택 타이머의 세부 애니메이션까지 검증했다고 표현하지 않는다.

선수 카메라를 구현하지 않는 기본 게임에서는 챔피언 큰 아트와 경기장 분위기의 배경을 사용할 수 있다. 실제 경기 중에는 챔피언 초상화를 지도 위 유닛처럼 이동시키되, 화면 하단 초상화와 이름을 계속 연결한다. 지도 움직임은 게임 시뮬레이션의 표현이며 방송 캡처에서 관찰한 실제 이동 궤적을 재현했다는 뜻이 아니다.
