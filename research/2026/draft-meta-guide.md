## 대회 분리와 시점

대회 키와 단계로 자료를 먼저 분리한다. 컵·First Stand·1·2R·Road·3~5R·플레이인/플레이오프·MSI·월즈를 섞지 않는다. REG12가 명시되어 있으면 날짜가 늦어도 후반 풀로 바꾸지 않는다. 월즈는 확보한 모든 월즈 세트를 사용하고 특정 단계나패치만 골라 부분 집계하지 않는다.

기본 ‘대회 전체 기록’은 해당 대회 전체의 회고 참고다. 현재 패치는1배, 동일 대회의 다른 패치는0.3배로 추천의 실제 픽·승·맞대결·동반 기록에 가중치를 준다. ‘현재 시점 참고’는 같은 대회에서 게임 날짜 이전 기록만 남긴다. 공백이면 다른 대회나 전 리그 주간 메타로 돌아가지 않는다. 미관측 후보는 기존 선수 숙련도 기반의 ‘대체 픽’으로 구분한다.

## 점수와 OP

- OP는 밴이 확인된 적용 패치 1세트 10경기 이상·P/B 65% 이상·관측 역할 2픽 이상을 요구한다. 해당 패치 1세트가 없으면 같은 대회의 1세트를 참고하며 화면에 ‘대회’를 표시한다. 월즈는 밴을 확인한 1세트가 6경기여서 OP 기준을 충족하지 않는다.
- 카드의 픽·승수는 해당 대회 전체의 실제 역할 기록이고 P/B는 별도 설명된1세트 우선도다. 역할은 실제 출전 표본을 사용하며 FLEX를 보존한다.
- 추천 점수는 관측 우선도, 현재 패치 가중 픽 수와 소표본 보정 승패, 해당 세트 번호의 실제 픽 경향, 해당 선수의 사용 기록·기존 숙련 추정, 현재 선택된 동반 챔피언·같은 라인 상대 기록을 조합한다. 승패는8경기의50% 사전값으로 수축시키고 동반/맞대결 효과도 표본 수로 제한한다. 단독 승률을 실제 상성의 인과효과로 간주하지 않는다.
- 픽 차례는 우리 선수·조합을, 밴 차례는 상대 선수·상대가 이미 확보한 조합을 기준으로 평가한다. 밴픽 중 역할을 확정하거나 상대의 숨은 선택 계획을 읽지 않는다. 동반 기록은 현재 공개 픽만 사용한다.
- 화면의 참고 점수는 밴픽 순위에 쓰는 스코어다. 화면에서 조회 모드를 전환해도 AI의 선택은 바뀌지 않는다.

## 자동 밴픽

우리 팀과 상대 팀 모두 현재 대회의 패치별 실전 챔피언·포지션 기용 빈도를 우선한다. 같은 대회의 이전 패치에는 낮은 가중치를 준다. 게임 패치의 기록이 비면 해당 대회에서 가장 가까운 이전 패치를 쓰고, 이전 패치도 없으면 그 대회의 첫 패치를 쓴다. 기록은 시즌 재현을 위해 해당 패치 전체를 참고한다. 선수 개인의 2026년 숙련과 대회 출전 보정에는 게임 날짜 이전 기록을 적용한다.

현재 패치에서 기용이 적거나 없는 챔피언은 보통 뒷순위다. 숙련도 76 이상에 최근 동일 포지션 공식전 6회 이상 또는 해당 대회에서 게임 날짜 이전에 동일 포지션 2회 이상 출전한 선수에게는 조커픽 보정을 준다. 다른 라인 기용이 대부분인 챔피언에는 포지션 근거를 추가로 확인한다. 피어리스로 주력 픽이 소진되면 해당 패치의 후순위 픽과 숙련도 높은 조커픽을 비교한다. 이미 고른 챔피언과의 스킬 연계도 점수에 반영한다.

선택 중에는 가능한 포지션 조합을 모두 비교하며 픽 이후까지 포지션을 확정하지 않는다. 자동 배치와 경기 입력에서도 실전 포지션을 인정하므로 원딜 코르키처럼 기존 챔피언 역할 목록에 빠진 포지션을 제대로 배치할 수 있다.

## 선택 동작과 검증

전체 챔피언과 메타 카드의 선택은 미리보기이며, 선택한 사진 아래의 ‘픽’ 또는 ‘밴’ 버튼 하나로만 확정한다. 버튼을 중첩하지 않고 차례 번호·선택 챔피언을 다시 확인한다. 소진·밴·대회 유예는 추천에서도 제외하고 다음 후보로 채운다. 목록의 스크롤을 보존한다. 최종 포지션은20행동 후60초 배치 단계에서 자유롭게 정한다.

단위 테스트는 대회 오염 방지·전체 세트 보존·시점 경계·실제 조합/맞대결의 점수 반영·미관측 후보 표시·난수 불변을 확인한다. 브라우저에서는 수동 밴과 픽의 사진 아래 버튼, 실제 확정, 모바일·스크롤·대회별 자료를 검사한다. 국제전/후반 단계 화면 일부는 날짜를 설정한 검증 상태이며 시즌 전체를 수동 플레이했다고 표현하지 않는다.
