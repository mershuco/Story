# VSChamp 라인전 카운터

2026년 11월 27일 공개 자료에서 챔피언 173명의 하드 카운터와 일반 카운터를 확인했다. 3,511개 원본 항목을 게임의 챔피언 ID와 포지션에 맞춰 중복 제거하고 포지션 조합으로 펼쳐, 하드 479개와 일반 2,478개를 적용했다. 아이템·룬·소환사 주문, 같은 라인에서 만나지 않는 포지션, 설명에서 라인전은 검색 대상 챔피언이 명확하게 유리하다고 밝힌 중후반 카운터는 제외했다. 바텀은 원딜과 서포터의 교차 상성을 포함한다. 양방향 상성이 있으면 등급 차이만 반영한다. [VSChamp](https://vschamp.lol/)

15분 전까지 상성 우위는 탑·미드 솔로킬과 바텀 듀오킬이 발생하는 빈도와 방향에 반영된다. 갱킹 성공률에는 작은 효과를 준다. CS 확보와 상대 CS 제한을 각각 계산하고, 해당 CS는 기존 미니언 골드 계산에 들어간다. 15분 이후에는 쌓인 CS와 골드의 영향이 이어진다. 선수 기량·숙련도와 기존 챔피언 성장 곡선도 계속 적용된다.

사이트 수치는 정성적 설명이다. 빈도와 골드 차이는 게임 밸런스 값이며, 패치별 LCK 실측 확률을 제공하는 자료는 확인하지 못했다. 동일 능력치·조합으로 시드 1~1,000번을 비교했을 때 15분 전 이렐리아가 나르를 상대로 솔로킬을 한 번 이상 얻은 비율은 21.2%에서 40.9%로, 평균 CS 리드는 4.3개에서 33.6개로 늘었다.

재생성 스크립트는 공개 응답을 입력으로 받는다. 배포 데이터에는 챔피언 ID, 배정 포지션, 하드·일반 등급을 저장하고 원문은 보관하지 않는다. [원본 데이터](https://vschamp.lol/champ.json?v=1.2.7)
