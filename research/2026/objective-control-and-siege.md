# 현상금·미니맵·연속 공성 v9

검토일: 2026-11-25. 실제 규칙과 확인 범위, 팬 게임용 환산값을 분리한다.

## 확인한 LCK 사례와 범위

- [GEN–T1, 2025 LCK 플레이오프 1세트 공식 하이라이트](https://www.youtube.com/watch?v=TqaFYfQBYD4): 공식 영상 페이지는 이 환경에서 재생되지 않았다. [공개 미러](https://www.dailymotion.com/video/x9qy0ao)의 플레이어 메타데이터와 영상 탐색용 연속 프레임 시트를 내려받아 후반부 바론·강화 미니언의 미드 전진·수비 교전·사이드 압박 장면을 시각적으로 확인했다. 연속 영상 재생이나 개별 포탑의 정확한 파괴 시각·횟수는 확인하지 못했다. 게임에 영상 프레임을 포함하지 않는다.
- [인벤, 2026-08-26 KT–BRO 경기 기사](https://www.inven.co.kr/webzine/news/?keyword=e2026&news=319986): 바론 이후 골드 확대, 마지막 세트의 탑 억제기와 넥서스 포탑 하나 파괴, 남아 있는 바론으로 추가 공격했으나 제리의 수비로 저지된 사례를 본문에서 확인했다. 여러 구조물을 연속 공략할 수 있어야 하고, 바론만으로 승리를 보장해서는 안 된다는 설계 근거다.
- 두 자료는 정성적 참고다. 전체 LCK 경기 영상을 시청하거나 수백 경기의 공성 전환율을 통계적으로 학습한 결과가 아니다. 아래의 피해 계수·건물 수 예산은 실제 LCK에서 측정한 수치가 아니다.

## 게임에 적용한 공성 판단

- 매 운영 구간에서 적 기지 경로의 남은 체력, 생존 공격 인원, 최근 사망한 수비 인원, 챔피언의 미니언 정리 능력을 평가한다. 끝낼 가능성이 있는 경로는 다음 오브젝트보다 먼저 공략한다. 실제 넥서스 체력이 0이 되어야 승리한다.
- 바론 운영은 생존 인원이 충분하고 미니언이 준비된 경우 최대 3개 라인으로 나눈다. 일반 한타에서 3킬 이상, 킬 차이 2 이상으로 크게 이기면 최대 2개 라인을 압박한다. 인원이 부족하면 한 라인으로 모인다.
- 한 운영 묶음의 일반 구조물 파괴 예산은 바론 4개, 일반 대승 3개다. 라인별 피해와 구조물 순서를 지키므로 이 수만큼 반드시 파괴하지 않는다. 넥서스 마무리 기회가 생기면 이 예산보다 경기 종료를 우선한다. 바론 유지 중 다음 공성에서도 추가 파괴할 수 있다.
- 미니언이 준비되지 않은 보조 라인은 제외한다. 공성한 라인의 미니언 준비도는 내려가며 시간이 지나면 다시 회복된다. 라인 이동에도 시간을 사용하고, 수비진이 부활하면 일반 대승의 추가 라인 전환을 멈춘다.
- 교전 사망에 따른 공성 인원 제한과 강화 보유자 제거를 반영한다. 정확한 서버 사망 시간·스킬·아이템·순간이동·분산 인원의 프레임별 피해는 재현하지 않는다. 1–3–1, 두 라인 분산의 역할 배치와 피해 분배는 장면 모델이다.

## 오브젝트 현상금

- [Riot 11.23 패치](https://www.leagueoflegends.com/en-us/news/game-updates/patch-11-23-notes/): 열세 판단에 골드·경험치·용·포탑을 사용하고, 현상금은 팀 전체에 분배한다. 외곽 포탑 기본 250G, 내부·억제기 포탑 400G, 주요 몬스터 500G를 확인했다.
- [Riot 25.9 패치](https://www.leagueoflegends.com/en-us/news/game-updates/patch-25-09-notes/): 골드 차이의 최대 10%를 기본 현상금에 더하되 낮은 가치의 대상에는 적게 지급하고, 최대 1,000G로 제한하는 변경을 확인했다.
- 게임에서는 14분 이후 골드 열세 2,000G 이상이면서 골드·레벨·용·포탑의 가중 점수가 4,000 이상이면 15초 예고 후 활성화한다. 회복 기준과 해제 유예도 게임용 조정값이다. Riot의 비공개 활성화 수식을 복제했다고 주장하지 않는다.
- 포탑은 각 라인에서 실제 접근 가능한 첫 생존 포탑에 금색 테두리를 표시한다. 다음 포탑으로 이동하며 파괴된 포탑에 중복 지급하지 않는다. 억제기와 넥서스에는 현상금을 주지 않는다. 추가 현상금은 기본 포탑 보상 및 오브젝트 포기 견적 800–1,500G와 별도로 표시·지급한다.

## 실제 이미지와 중계 표시

- 배경은 Riot Data Dragon 소환사의 협곡 미니맵이다. [출처·해시](minimap-source.json).
- 포탑·체력별 포탑 상태·억제기·넥서스는 Riot 미니맵 UI 원본 이미지다. 팀 색상은 렌더링 시 적용한다. [출처·해시](structure-image-sources.json).
- 용 6종·바론·장로·보라색 유충은 기존 [Riot 원본 이미지](objective-image-sources.json)를 사용한다. 임시 몬스터 도형을 제거하고 생성 전·처치 후에는 원본 아이콘을 흐리게 표시하며, 공개된 사건 기록으로만 재생성 시간을 계산한다.
- 바론 180초·장로 150초의 보유 팀과 남은 시간을 팀 쪽 고정 카드로 표시한다. 보유자가 모두 사망하거나 시간이 끝나면 사라진다. 확보 이후 골드 표시는 해당 팀 관점의 골드 격차 변화다. 획득 장면은 x8에서도 결과를 읽을 시간을 준다.

## 검증

도메인 테스트는 현상금 예고·해제·실제 지급·중복 방지, 넥서스 우선과 부당한 종결 방지, 여러 라인·연속 포탑 공성, 미니언·생존 인원의 차이, 강화 실제 획득 팀·만료와 이전 v8 리플레이 보존을 검증한다. 브라우저에서는 실제 밴픽 화면과 별도 관전 상태를 사용해 데스크톱·390px 화면, 금색 테두리 이동, 원본 이미지 로딩, 고정 카드와 새로고침 보존을 확인한다. 별도 상태 주입 검사는 실제 경기에서 그 상황이 자연 발생한 것과 구분한다.
